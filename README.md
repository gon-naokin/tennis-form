# サーブ フォームチェック（試作版）

テニス班向けの、サーブ動画の骨格解析アプリです。10〜15 秒の動画を選ぶと、ブラウザの中で骨格を読み取り、肘・膝などの角度を表示します。サーバーは使わず、GitHub Pages だけで動きます。

## できること

- 動画に骨格を重ねて再生（1× / 0.5× / 0.25× / 0.1×、コマ送り）
- 肘の角度、脇の開き、トスの腕の上がり、左右の膝の角度、体の傾き、手首の高さを数値で表示
- フォームのチェック：トロフィーポーズとインパクトの 6 項目を目安と比べ、定型のコメントを表示
- トロフィーポーズとインパクトの瞬間を自動で探してジャンプ（外れたら「いまの位置をインパクトにする」で手動指定）
- 角度の時間変化をグラフ表示（なぞると動画がその位置に移動）
- 2 本の動画を、インパクトの瞬間をそろえて並べて比較

## フォームのチェックの目安

コメントは、角度が目安から外れたときに決まった文を出す仕組みです（AI による文章生成ではありません）。目安は一般的な指導内容をもとにした仮の値で、真横から撮った動画を前提にしています。数値と文は `docs/js/coaching.js` の `GUIDE` と `CHECKS` にまとまっているので、班の教え方に合わせて書き換えられます。

| 場面 | 項目 | 目安 |
|---|---|---|
| トロフィーポーズ | 膝の曲げ（深く曲げた側の膝の角度） | 140° 以下 |
| トロフィーポーズ | 利き腕の肘の高さ（脇の開き） | 80° 以上 |
| トロフィーポーズ | トスの腕の上がり | 130° 以上 |
| インパクト | 肘の伸び | 160° 以上 |
| インパクト | 打点の高さ（手首の高さ ÷ 鼻の高さ、足首基準） | 1.2 倍以上 |
| インパクト | 膝の伸び（伸びている側の膝の角度） | 155° 以上 |

インパクトの 3 項目は、打つ瞬間がコマの間に落ちることがあるため、前後 0.1 秒でいちばん大きい値を使います。

## プライバシー

動画は端末の中だけで処理し、どこにも送信・保存しません。外部から読み込むのは次の 3 つだけです。

- 骨格検出ライブラリ MediaPipe Tasks Vision（cdn.jsdelivr.net、版は `docs/js/app.js` の `MP_VERSION` で固定）
- 骨格モデル `pose_landmarker_full`（storage.googleapis.com）
- 書体 Zen Maru Gothic（Google Fonts）

## ローカルで動かす

```
python -m http.server 8788 --directory tennis-form/docs
```

`http://localhost:8788/` を開きます（`file://` で直接開くと動きません）。

## テスト

角度計算、サーブ検出、フォームのチェックの判定のテストです。

```
node --test tennis-form/tests/pose-math.test.mjs tennis-form/tests/coaching.test.mjs
```

## GitHub Pages で公開する

1. GitHub に新しいリポジトリを作り、この `tennis-form` フォルダの中身を push する
2. リポジトリの Settings → Pages で、Branch を `main`、フォルダを `/docs` にする

## ファイル構成

| ファイル | 役割 |
|---|---|
| `docs/index.html` | 画面 |
| `docs/css/style.css` | 見た目（戦績アプリと同じ配色） |
| `docs/js/app.js` | 動画の読み込み、解析、再生、比較 |
| `docs/js/pose-math.js` | 角度計算、サーブ検出（画面に依存しない計算だけ） |
| `docs/js/coaching.js` | フォームのチェックの目安と定型コメント |
| `docs/js/chart.js` | 折れ線グラフ |
| `tests/` | `pose-math.js` と `coaching.js` のテスト |

## 知っておくこと

- 数値は 1 台のカメラ映像からの推定です。撮る角度で変わるので、同じ条件で撮った動画どうしの比較に使ってください。
- ラケットとボールは検出しません。インパクトは「利き手の手首が最も高い瞬間」、トロフィーポーズは「その直前で膝が最も曲がった瞬間」として探しています。
- 解析は、動画を再生しながら読み取り、取りこぼしたコマだけ後から読み直す 2 段階です。
- 目安の数値は、実際のサーブ動画で確かめて決めたものではありません。使いながら調整する前提です。
